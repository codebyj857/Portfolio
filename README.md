# Joya Parveen | AI/ML Engineer Portfolio

**Live site:** https://joya-parveen-portfolio.netlify.app/

The personal portfolio of Joya Parveen, a BTech CSE (Data Science) graduate focused on AI/ML. It brings together my projects, writing, research, skills and certifications in one animated, 3D-styled page.

## What's on the site

- **Hero:** a welcome video, typing role animation and quick links to my resume and CV
- **About, Education and Languages**
- **Skills:** grouped across programming, data science, machine learning, deep learning, NLP and LLMs, RAG and agents, MLOps, visualization and tools
- **What I do:** the kinds of work I can help with
- **Projects:**  AI/ML projects, each linked to its GitHub repository
- **Writing:** articles from my Medium blog
- **Experience, Leadership and Certifications**
- **Contact**

## Built with

- HTML, CSS and vanilla JavaScript in a single `index.html`
- Hosted on Netlify


## Run it locally

1. Clone the repository:
   ```bash
   git clone https://github.com/codebyj857/Portfolio.git
   cd Portfolio
   ```
2. Open `index.html` in a browser, or start it with the **Live Server** extension in VS Code.

No build step or dependencies are needed.
